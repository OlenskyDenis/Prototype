# Скіл спілкування українською мовою (Ukrainian Language Skill)

Цей скіл визначає вимоги щодо мови комунікації: все спілкування, пояснення, повідомлення та описи у чаті повинні вестися виключно українською мовою.

## Основні вимоги та стандарти

1. **Мова відповідей та описів**:
   - Усі відповіді користувачеві, пояснення дій, звіти про виконану роботу, підсумки змін та системні описи **ОБОВ'ЯЗКОВО** надаються українською мовою.
   - Заборонено без прямої вимоги користувача повертатися до англійської або інших мов у текстовому спілкуванні.

2. **Технічна термінологія**:
   - Використовувати коректні та сучасні українські терміни зі сфери комп'ютерних наук та розробки програмного забезпечення:
     - *repository* → репозиторій
     - *branch* → гілка
     - *commit* → коміт
     - *pull request* → запит на злиття (або пулл-реквест)
     - *deployment* → розгортання
     - *build* → збірка
     - *debugging* → налагодження
     - *performance* → продуктивність / швидкодія
     - *dependency* → залежність
     - *testing* → тестування

3. **Збереження коду та команд**:
   - Вихідний код програм, назви функцій, змінних, класів, інтерфейсів, файлів, шляхи, команди консолі та бібліотеки зберігаються в оригінальному вигляді без перекладу (наприклад: `uv tool install`, `git status`, `resolve-template.ps1`, `function handleSubmit()`).
   - Форматування посилань на файли та розмітка Markdown залишаються стандартними.

4. **Описи та артефакти**:
   - Усі звіти, плани, резюме завдань та документація, що створюються для користувача, формулюються українською мовою.
